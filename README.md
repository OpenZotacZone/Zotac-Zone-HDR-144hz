# Zotac ZONE HDR and 144hz fix
[![OpenZONE Discord](https://img.shields.io/badge/Discord-%235865F2.svg?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/YFhK768cex)

This script fixes the green tint on Bazzite/Fedora Atomic in HDR mode and enables 144hz for the integrated OLED screen


## Description
This script is based on the work done by u/tocirahl who wrote a great tutorial on [reddit](https://www.reddit.com/r/ZotacZone/comments/1oht7y0/green_tint_in_hdr_on_bazzitesteamos_try_this_fix/)

## Setup
1. Download install_zotac_hdr.sh
2. Open a terminal in the folder where the file is located by right clicking and selecting "open terminal here" in KDE
3. Make the file executable by running this:
   
   `chmod +x install_zotac_hdr.sh`
   
5. Run the script with sudo:
   
   `sudo ./install_zotac_hdr.sh`
   
6. Switch to Gamemode and check if 144hz is available and if the HDR profile works in an HDR compatible game
